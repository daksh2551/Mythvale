# Mythvale — Realm Atlas Upgrade

## Included
- Added a World Atlas button to the pause menu.
- Shows the five story realms, short descriptions, visited/current/ahead status, and estimated progress for the current 4,200-unit region.
- Atlas is read-only: it does not move the player, change checkpoints, grant rewards, or write separate progress.
- Non-story modes are labeled separately to avoid implying Arena/Dungeon progress is story progress.
- Added close/back handling and responsive scrollable panel.
- Synchronized `game/index.html` and `www/index.html`.

## Checks
JavaScript syntax, repository web-preparation script, source synchronization, and ZIP integrity were checked. Android build and actual device gameplay are not verified by these checks.
